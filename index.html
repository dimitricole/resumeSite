Agentic finance

AI agents that can read a ledger and act on it. I build internal MCP servers that let an agent research XRP Ledger (XRPL) data and execute on-chain transactions.

What agentic finance looks like

The agent works through tools, calling the ledger the same way it would call any other API. The second example uses x402: the API answers "402 Payment Required", and the agent pays on the XRP Ledger and retries, with a person approving the payment before anything is signed.
